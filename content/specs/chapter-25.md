## Sections
**Overview** — The simplest system in the corpus: pick the day's ONE task before anything
else; write the block's output before starting; close the loop out loud when done. The
day becomes a win by construction.

**01 — The one task rule** — Why one: attention divides poorly (filter logic, Ch 1); the
one task is the day's primary objective — everything else is maintenance. Choice
discipline: the one task is chosen by aim (Ch 4's backwards plan), not by urgency or mood
(mood = weather, Ch 19).

**02 — The winner's loop** — The loop: write the block's specific output → execute → check
off → say the outcome aloud. Why it works: completion is a psychological event — closed
loops release attention (Masicampo & Baumeister; honest framing from Ch 23), and banked
wins are the day's motivation (action first — Dimidjian). The audible close is the ritual
that makes completion felt.

**03 — Escalation** — The habit scales: 20-minute blocks → 45 → 90; one task → one task +
one maintenance block. Escalation is paced by floors (Ch 18), never by inspiration
(Ch 19): the day the floor version is done is still a win.

**04 — The day's shape** — Morning: choose + write the one task (Morning Calibration
synergy). Day: one winner's loop, then maintenance in batches (Ch 24). Evening: close the
log — one line: what closed, what's queued (open-loop hygiene, Ch 23).

**05 — Why this one habit beats the big systems** — The one daily habit outlives the
elaborate system because its failure mode is small (a 20-minute block is always possible)
and its psychology is sound (identity votes daily, Ch 8/18). The "productivity glitch"
(Ch 26) is this principle applied to the whole system.

**Key Ideas / Apply Today** — Key ideas: one task; output before block; close the loop
aloud; floors scale; small failure modes win. Apply: choose tomorrow's one task tonight;
write the block's output; run one loop and close it aloud; log one line; escalate by one
block next week.
