## Sections
**Overview** — Discipline reframed: not a tank you drain (ego depletion failed replication) or
a trait you lack — a system of demand-reduction and identity votes. Jocko: discipline equals
freedom — the honest engineering version.

**01 — The dopamine story, corrected** — What the "dopamine detox" actually is (Sepah's
CBT-style protocol: stimulus control + exposure-response prevention for compulsive tech use)
vs the story (no evidence fasting resets receptors — Harvard Health summary; Lembke's
homeostasis as the reputable frame). Keep the behavior (reduce compulsive stimulation),
drop the neuro-magic. Cost framing: every urge-gratification loop raises the base need —
compulsion management is discipline's substrate.

**02 — The 2-minute rule** — Start size trumps willpower: the rule's core (any habit's start
shrunk to under two minutes) rests on behavioral activation's engine (action precedes
motivation — Dimidjian). The first rep is the only decision.

**03 — Identity votes** — Clear's vote metaphor: each discipline-relevant action votes for an
identity; elections are won by consistency, not landslides. Misses are abstentions, not
cancellations.

**04 — The zero-day floor** — No zero days (real origin: a 2013 Reddit post by ryans01 —
say so): the floor version of any behavior that still counts. The floor is not the target;
it's the guarantee. Two-day misses are where streaks die; the rule: never two.

**05 — Environment is the discipline** — Reduction: phone in another room; defaults changed
(apps deleted, charger moved); friction engineering for the good loop (gym bag by the door).
Discipline as subtraction (Ch 26 family).

**Key Ideas / Apply Today** — Key ideas: demand-reduction; 2-minute starts; votes not
landslides; floors; environment. Apply: shrink one habit's start to <2 min; set the floor
version; remove one trigger from reach; define "never two" for misses; run the Dopamine
Detox correctly (quarterly day).
