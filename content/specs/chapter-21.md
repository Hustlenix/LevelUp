## Sections
**Overview** — The ritual: a weekly (or daily) protected block for the single hardest task —
entry ritual, one objective, no interruptions, visible progress. "God mode" as a name for
deep work (Newport: focus without distraction — reference him once, briefly).

**01 — What the block is** — Structure: 60–90 minutes (fits the 90-minute attention cycle
literature — keep as observation, no precise claims), one objective written before entry,
one progress marker, closed loop. The block is scheduled, not awaited (Ch 12 family).

**02 — The activation protocol** — Entry ritual (the 5 minutes before): slow breathing
(state entry, Ch 9 family), the block's single output written down, chosen interpretation
("this is training, not a test"). The wandering-mind policy: attention will leave (~47%
baseline wandering — Killingsworth & Gilbert data from Ch 20); the skill is returning
without self-punishment, not never leaving.

**03 — Protecting the block** — Interruptions are expensive (Mark: interrupted workers work
faster, more stressed — real cost, no 23-minute numerology). Environment lockdown: phone
elsewhere, notifications off, tabs closed, one visible next-action. The block's protection
is the environment's job, not willpower's.

**04 — The default mode dividend** — The resting brain (default mode network — describe
plainly: the mind's background processing during rest) — why blocks pair with genuine rest:
the review slot and the offline hours are where integration happens. (No neuroscience
claims beyond "the brain consolidates during rest" — safe.)

**05 — The weekly rhythm** — God Mode as the Perfect Week's crown: one protected block per
week minimum, same time, advance-prepped (Sunday). Log four weeks of outputs — your own
personal evidence base (replaces any borrowed "5x" claim).

**Key Ideas / Apply Today** — Key ideas: block > motivation; entry ritual; environment
protection; return, don't punish; rest is integration. Apply: pre-pick the week's hard task;
write the entry ritual; run one full block this week; log the output; schedule rest after.
